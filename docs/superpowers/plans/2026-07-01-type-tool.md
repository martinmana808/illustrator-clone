# Type Tool Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** A Type tool (T): click the canvas to place a text object and type into it inline (printable chars, Backspace, Enter/newline); edit font size and family; text exports to SVG. Empty text objects are discarded on finish.

**Architecture:** Headless `TypeTool` state machine wrapping `paper.PointText`. Wired into `installTools` under a new `"type"` tool id, with key events forwarded from the canvas while editing. A `TypePanel` provides font size/family controls and a content textarea.

**Tech Stack:** Paper.js `PointText`, TypeScript, Vitest.

## Global Constraints

- New `ToolId` member `"type"`; shortcut **T**.
- While the Type tool is actively editing, keystrokes go to the text (not tool switches); Escape finishes.
- Empty text is removed on finish.
