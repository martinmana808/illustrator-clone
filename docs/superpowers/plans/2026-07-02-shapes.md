# Shape Tools Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Six drag-to-create shape tools (Rectangle, Rounded Rectangle, Ellipse, Polygon, Star, Line) with Shift/Alt/arrow modifiers, producing real editable paths.

**Architecture:** Pure geometry builders in `engine/shapes.ts`; one `ShapeTool` state machine parameterized by kind; routed through `useActiveTool.ts` for any shape ToolId.

**Tech Stack:** Paper.js builders, TypeScript, Vitest.

## Global Constraints
- New shapes get default fill `#c8c8cc` + black stroke.
- Rounded-rect radius default 12 (arrow ±2); polygon default 6 sides; star default 5 points, inner = outer × 0.5.
- Shapes are real content (committed to history on pointer-up).
